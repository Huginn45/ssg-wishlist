☁️ Live Shared Backend Setup

Connect a free cloud database so every SSG member who opens your Vercel site on their phone sees real-time wishlists automatically.

Tip: For permanent Vercel deployment, paste this URL into BACKEND_URL inside config.js before pushing to Vercel!
How to create a free Firebase Realtime Database:
  1. Go to console.firebase.google.com and click Create a project.
  2. In the left sidebar, click Build → Realtime Database → Create Database.
  3. Choose Start in test mode and click Enable.
  4. Copy your database URL and paste it into config.js (BACKEND_URL) or above!
How to use a Google Sheet as your database:
  1. Create a new Google Sheet (sheets.new) and click Extensions → Apps Script.
  2. Copy the code from google-sheets-backend.gs and paste it into the editor, then save.
  3. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone.
  4. Copy the Web App URL and paste it into config.js (BACKEND_URL) or above!
